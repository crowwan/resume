## B. HTML 형식 평가 — 합격 수준
- **가독성**: 헤더 위계·태그라인 박스·섹션 밑줄 명확. 축 칩 도움됨(과하지 않음). 단 일부 bullet 볼드 과다.
- **시맨틱**: h1→h2→h3 위계 적절, 기술스택 table, ul/li 정상.
- **ATS**: 양호 — 전부 실제 텍스트, 단일 컬럼, 표준 태그. 파싱 쉬움.
- **인쇄/PDF**: @media print 충실(A4·page-break·색 강제). Solutions 카드(5 bullet)만 페이지 경계 주의.

## 형식 개선점 3가지
1. 한 bullet 내 `<strong>` 1~2개로 제한(볼드 과다 → 강조 변별력↓).
2. 헤더에 연락처(이메일) 추가 검토.
3. 긴 카드를 `<section>`/`break-inside:avoid`로 감싸 페이지 분할 방지.

## 내용 보강 3가지 (통과 전제 상향)
1. "수십 분" → 실측/정성.
2. Account 첫 bullet에 결제 정확성 보장 방식.
3. "(성장)/(일할 계산)" 괄호 메모를 본문 문장으로 흡수.
