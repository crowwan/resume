## 운영 룰

- 각 이력서 버전은 **덮어쓰지 않고 보존**한다: `resume-vN.md` (N=1,2,3…).
- 각 버전의 리뷰는 짝으로 남긴다: `resume-vN-review.md` (항목별 점수 + 총점 + 통과여부 + 면접관 피드백).
- **리뷰어는 면접관 시각.** `findings/`·`interviews/` 등 내부 자료를 **모른 채** 이력서 결과물만 보고 채점한다. (서브에이전트로 호출, 입력은 해당 `resume-vN.md` 하나뿐)
- **발명 검증은 생성자(작성자)의 책임.** 리뷰어는 "구체적·방어 가능해 보이는가"만 본다.
- 채점 기준: [../EVALUATION-RUBRIC.md](../EVALUATION-RUBRIC.md) (8항목×5점=40, 통과 ≥33 + 항목1·2 ≥4 + 치명결함 0).
- **통과한 버전**이 나오면 그 내용을 루트 `resume.md`로 **승격**한다(버전 파일은 그대로 보존).
