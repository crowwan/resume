### 웹·로컬 소프트웨어 연동 Electron 데스크톱 앱  (2024.07~2025.12, 이후 단독 운영)
웹에서 만든 보철 케이스를 사용자 PC의 CAM 소프트웨어로 넘기는 사내 연동 앱(Linker)을, 다운로드·압축 해제·수동 투입을 거치던 흐름에서 자동 전달로 재설계하고 단독 운영했습니다.
- 초기 로컬 서버 방식이 Chrome LNA 정책에 막혀, 20여 방안을 비교한 끝에 Custom Protocol 중간 레이어로 재설계
- WebSocket은 곧 같은 LNA 정책 적용 대상이라 제외하고 HTTPS 로컬 서버도 같은 이유로 무효라, 장기 안정성을 채택 기준으로 선택
- 좌표계와 파일 전달 방식이 제각각인 외부 CAM 12종을 단일 변환·연동 인터페이스로 통합
- 명세 없던 기존 연동을 특성화 테스트로 먼저 고정한 뒤 구현으로 통과시켜, 버그 수정을 곧 살아있는 스펙으로 운영
- 초기 핵심이던 로컬 서버를 수명이 다하자 직접 폐기하고, 딥링크·세션·CAM 연동 이슈를 2026년까지 단독 책임
- 데이터 전달을 위해 양방향성을 포기한 트레이드오프가 앱 실행 감지 부채로 남아, 포커스 휴리스틱 의존을 핵심 경로에서 분리하는 방향으로 개선 중
`기술` Electron · React · TypeScript · Custom Protocol · Datadog
